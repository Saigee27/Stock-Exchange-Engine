# Overview

Trading mechanics describe how executed market activity is measured and how a trader's position changes in value.

Core concepts:

- Trading Volume
- OHLC
- Return
- Profit & Loss (P&L)
- Position Sizing

---

# Trading Volume

Trading Volume is the total number of shares actually executed during a specific period.

Orders that remain in the order book without execution do **not** contribute to trading volume.

### Formula

```text
Trading Volume = Σ Executed Quantities
```

### Example

```text
Trade 1 = 200 shares
Trade 2 = 50 shares
Trade 3 = 150 shares

Volume = 200 + 50 + 150
       = 400 shares
```

---

# OHLC

OHLC represents the four important prices recorded during a trading period.

| Symbol | Meaning |
|---|---|
| O | Open |
| H | High |
| L | Low |
| C | Close |

```text
Open  = First Executed Price
High  = Highest Executed Price
Low   = Lowest Executed Price
Close = Last Executed Price
```

### Example

```text
Trades:

₹250
₹245
₹260
₹255
₹270
₹240
₹265
```

```text
O = ₹250
H = ₹270
L = ₹240
C = ₹265
```

OHLC data is commonly used to construct candlestick charts.

# Return

Return measures the percentage gain or loss relative to the initial price.

### Formula

```text
Return = (Current Price - Initial Price) / Initial Price
```

### Percentage Return

```text
Return % = ((Current Price - Initial Price) / Initial Price) × 100
```

### Example

```text
Initial Price = ₹200
Final Price   = ₹230

Return % = ((230 - 200) / 200) × 100
         = 15%
```

```text
Positive Return → Gain
Negative Return → Loss
Zero Return     → Break-even
```

# Profit & Loss (P&L)

P&L represents the monetary profit or loss generated by a trading position.

For a simple long position:

### Formula

```text
P&L = (Current Price - Entry Price) × Quantity
```

### Example

```text
Entry Price   = ₹200
Current Price = ₹230
Quantity      = 50 shares

P&L = (230 - 200) × 50
    = ₹1,500
```

Therefore:

```text
P&L > 0 → Profit
P&L < 0 → Loss
P&L = 0 → Break-even
```

### Realized vs Unrealized P&L

**Realized P&L** is the profit or loss after a position has been closed.

**Unrealized P&L** is the current paper profit or loss of an open position.

For an open long position:

```text
Unrealized P&L = (Current Price - Entry Price) × Quantity
```

# Position Sizing

Position sizing determines how many shares a trader can purchase based on available capital and share price.

### Formula

```text
Quantity = Available Capital / Share Price
```

### Example

```text
Available Capital = ₹15,000
Share Price       = ₹300

Quantity = 15,000 / 300
         = 50 shares
```

If the stock later rises to ₹320:

```text
P&L = (320 - 300) × 50
    = ₹1,000
```

Position size directly affects the magnitude of profit or loss.

```text
Larger Position
      ↓
Same Price Movement
      ↓
Larger Profit / Loss
```

# Key Takeaways

- Trading Volume measures executed trading activity.
- Unexecuted orders do not contribute to trading volume.
- OHLC records the first, highest, lowest and last executed prices.
- Return measures percentage gain or loss.
- P&L measures the monetary gain or loss of a position.
- Realized P&L occurs after closing a position.
- Unrealized P&L represents the current value of an open position.
- Position sizing determines how many shares a trader holds.
- Larger positions create larger gains or losses for the same price movement.
- These concepts form the foundation of the trader and portfolio systems in SEE.
