# Stock Exchange Simulator

A C++ stock market simulator that models buying, selling, order matching, market events, and portfolio management.

## Features
- Buy and sell stocks
- Dynamic stock prices
- Portfolio tracking
- Order book simulation (planned)
- Market news events (planned)

## Tech Stack
- C++
- STL
- Git
